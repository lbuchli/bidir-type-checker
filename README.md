# Bidirectional Type Checking

This is an exercise to implement bidirectional type checking.

Example tasks:
- Add ternary if
- Add arrays (medium)
- Add lambdas with annotated types (λx:t.y) (hard), Add lambdas without annotated types (harder)
- Add functions (hard!)
- Add user defined types (even harder!)
- Add type polymorphism (you have too much time)

Good resources: 
- Type Systems and Programming Languages by Benjamin Pierce (Book). Describes rules and implementations for a variety of type system features.
- [Bidirectional Typing](https://www.cl.cam.ac.uk/~nk480/bidir-survey.pdf) by Jana Dunfield and Neel Krishnaswami (Paper). Describes general design principles for bidirectional typing.
